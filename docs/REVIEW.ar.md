# مراجعة حالة المشروع

تاريخ المراجعة: 17 أكتوبر 2026.

## النتيجة

المستودع منظم لتوثيق تجربة درون وأنظمة مدمجة، لكنه لا يتضمن برنامج طيران متكاملًا. المراجعة اعتمدت على ملفات المستودع والصور المتبقية، ولم تتضمن اختبارًا فعليًا للعتاد أو بناءً باستخدام حزمة Arduino.

## الموجود

| الجزء | الحالة |
| --- | --- |
| وصف عربي وإنجليزي | موجود |
| صور التجميع والكود وقراءات الحساس | موجودة |
| تفسير الكود الظاهر بالصور | موجود |
| مثال اختبار ESC منفرد | موجود ومنفصل عن الكود المصوّر |
| تعليمات التشغيل والتوصيلات المقترحة | موجودة |
| خطة التطوير | موجودة |

## النواقص الأساسية

1. **الكود الأصلي الكامل:** ملفات الثروتل والحساس الظاهرة في الصور غير موجودة بصيغة قابلة للفتح والبناء. إضافتها أهم خطوة لتمثيل العمل الأصلي.
2. **مخطط توصيل فعلي:** المنافذ المقترحة لا تكفي لإعادة التجميع؛ يلزم توثيق توزيع الطاقة وESC والمستقبل والحساس والأرضي.
3. **مواصفات المكونات:** أسماء وموديلات المحركات وESC والبطارية والمستقبل والحساس، مع الجهد والتصنيفات المناسبة.
4. **بناء واختبارات موثّقة:** إصدار حزمة Arduino ومكتبة Servo، ونتيجة Verify للمثال المرفق، وسجل نتائج الاختبارات على العتاد. صورة التجميع السابقة تخص كودًا مختلفًا.
5. **التحكم بالطيران إن كان هدف المشروع:** قراءة قنوات التحكم، ومعايرة الحساس، وتقدير الاتجاه، والتحكم بالاتزان، وتوزيع أوامر المحركات، والتعامل مع فقد الإشارة. هذه الوظائف غير موجودة في المثال المرفق.
6. **إثبات النتيجة الفعلية:** فيديو أو سجل اختبار يوضح ما تم تشغيله بالفعل، دون استنتاج الطيران من صور التجميع.

## مراجعة المثال المرفق

بفحص المصدر: يمنع بدء الاختبار قبل التسليح، ويختار قناة واحدة، ويعيد الأمر إلى الحد الأدنى بعد ثانيتين، وينهي جلسة التسليح بعد عشر ثوانٍ دون بدء اختبار. لا يظهر في هذه المراجعة خلل منطقي واضح ضمن هذا النطاق المحدود، لكن ذلك لا يثبت توافقه مع العتاد.

الحد الأدنى 1000 ميكروثانية وأمر الاختبار 1100 ميكروثانية افتراضات تحتاج إلى مطابقة دليل ESC. البرنامج لا يقرأ جهاز التحكم أو الحساس ولا ينفذ اتزان الطيران. افصل بين نتائج هذا المثال ونتائج الكود الأصلي.

## الأولوية التالية

أضف ملفات Arduino الأصلية وموديل الحساس والمستقبل أولًا؛ بعدها يمكن التحقق من التوصيلات والبناء وتحديد ما يلزم دمجه. لا يُنصح بإضافة برنامج طيران مفترض قبل معرفة المكونات الفعلية.
