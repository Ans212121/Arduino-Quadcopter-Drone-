## نبذة المشروع

مشروع تعليمي يجمع بين التصميم الميكانيكي والإلكترونيات والبرمجة المدمجة، من خلال تجميع منصة درون رباعية واستكشاف إشارات التحكم بالمحركات وعرض بيانات التسارع والجيروسكوب.

## الأهداف

- دمج الهيكل والمحركات والمتحكم المدمج.
- استكشاف نبضات التحكم بوحدات ESC وإشارة الثروتل.
- مراقبة بيانات الحساسات باستخدام Serial Monitor.
- اختبار الوظائف منفردة قبل دمجها في نظام تحكم.

## مكونات البرمجيات

| الوحدة | الوظيفة |
| --- | --- |
| [اختبار ESC](firmware/esc_bench_test/esc_bench_test.ino) | اختبار قناة محرك واحدة في كل مرة بأوامر تسلسلية |
| [تشخيص الثروتل](firmware/throttle_diagnostic/throttle_diagnostic.ino) | قراءة النبضة وعرض الأمر المحسوب دون تشغيل المحركات |
| [منطق الثروتل](firmware/throttle_diagnostic/throttle_logic.h) | قبول نبضات 900–2100 وتقييد الأمر إلى 1000–1500 ميكروثانية |
| [تنسيق بيانات الحساس](firmware/sensor_output/sensor_output.h) | طباعة قيم المحاور الستة التي يزوّدها برنامج تشغيل الحساس |
| [الاختبارات](tests/throttle_logic_test.cpp) | فحص حدود الإدخال والتقييد وانتهاء مهلة الإشارة |

منفذ D2 في تشخيص الثروتل اختيار قابل للتعديل يحتاج تأكيدًا. منافذ مثال ESC هي D3 وD5 وD6 وD9. ملف تنسيق بيانات الحساس يحتاج برنامج تشغيل مناسبًا لموديل الحساس؛ لا يهيّئ الحساس ولا يقرأه بنفسه.

## مراحل التطوير

توثّق الصور تجميع المنصة ونتيجة تجميع كود ثروتل وعرض بيانات الحساس. نتيجة التجميع الظاهرة هي 3,620 بايت للبرنامج و262 بايت للمتغيرات العامة، وتخص الكود المصوّر ولا تمثل نتائج بناء الأمثلة الموجودة في المستودع.

## التشغيل والاختبار

راجع [المكونات والتوصيلات](docs/HARDWARE.md) و[دليل الاختبار](docs/BENCH_TEST.md). انزع جميع المراوح قبل تشغيل المحركات في الاختبارات.

اجتاز منطق الثروتل 11 حالة حدودية على الكمبيوتر. واجتاز ملف التشخيص ومساعد تنسيق الحساس فحص صياغة C++ بواجهات Arduino مبسطة. بناء الأمثلة باستخدام حزمة Arduino Uno والتحقق من تشغيلها على العتاد ما زالا مطلوبين.

## نطاق المشروع الحالي

يوفر المستودع تشخيصًا واختبارًا للمكونات. لا يتضمن قراءة الحساس الفعلية أو تقدير الاتجاه أو التحكم بالاتزان PID أو توزيع أوامر الطيران على المحركات. الطيران المستقر غير موثّق.
